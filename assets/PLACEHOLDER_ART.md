# Placeholder art — NOT final

Every sprite in this folder is a **throwaway placeholder** generated by code
(`tools/gen_placeholder_art.py`, Python + Pillow). They exist only so the game
is reviewable and playtestable. None of it is final, and none of it is AI-
generated art — it's procedurally drawn pixels.

Regenerate with:

    python3 tools/gen_placeholder_art.py

Replace these with real art before release.
